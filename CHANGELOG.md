# Changelog

## 1.0.0 – 2026-11-26

First version.

- Subjects, chapters and decks (flashcards, tests, notes) with colours, icons, archive and recycle bin
- JSON import (paste, browse, drag & drop) with preview, error messages, duplicate handling and AI-mistake repair; JSON export
- AI prompt templates in English and Bulgarian, editable, with "weak spots" and "fix my JSON" templates
- Flashcards with SM-2 spaced repetition, tests (timed, instant or end feedback), self-graded written answers
- Results with pages to re-read, review of missed items, "ask AI to explain"
- Study notes reader, statistics, global search, keyboard shortcuts
- Light / dark / sepia themes, accent colour, reading typography settings with live preview, English / Bulgarian UI
- Automatic daily backups, restore, in-app updates from GitHub Releases
